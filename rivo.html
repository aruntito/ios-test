GOOD TO KNOW

Questions, answered.

Do I need to share my social media password?

No. RIVO's intended customer flow should never request a social account password or one-time security code. Only provide the specific public URL or details a legitimate service needs.

Are the prices and services live?

No. This is a front-end prototype with sample catalogue data. Live rates, availability, delivery estimates and provider terms need verification before production.

How do I check my order?

Open Track order and enter your order reference. The live version will retrieve status from the order system.

What if I need help?

The production version will include support requests linked to an order reference, so customers can get help with the right context.
